# CEFR vocabulary datasets

The CSV files in this directory are unchanged copies from the
[Open Language Profiles CEFR-J repository](https://github.com/openlanguageprofiles/olp-en-cefrj).

- `cefrj-vocabulary-profile-1.5.csv` is the CEFR-J Wordlist Version 1.5,
  compiled by Yukio Tono at Tokyo University of Foreign Studies. The source
  repository permits research and commercial use at no charge when the
  dataset is cited properly. Copyright belongs to Tono Laboratory at TUFS.
- `octanove-vocabulary-profile-c1c2-1.0.csv` is the Octanove Vocabulary
  Profile C1/C2 Version 1.0, created by Octanove Labs. It is available under
  the Creative Commons Attribution-ShareAlike 4.0 International License.

See the source repository for the complete terms, disclaimers, and references.
